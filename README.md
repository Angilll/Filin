# 🦉 Филин

**Филин** — настольная программа для работы с заметками на локальном искусственном интеллекте. 
Она расшифровывает голосовые записи, автоматически придумывает заголовки, раскладывает заметки по папкам и понимает голосовые команды. 
Всё работает **полностью офлайн** — данные не покидают компьютер.

---

## 🎯 Что это за продукт, для кого и зачем

Программа создана для людей, которые много работают с текстом и голосом: студентов, исследователей, авторов, разработчиков. 

**Проблема:** ручная сортировка заметок отнимает много времени, а голосовые записи часто остаются нерасшифрованными и теряются. 
**Решение:** «Филин» автоматизирует этот процесс. Вы записываете голос, программа превращает его в текст, сама придумывает заголовок и предлагает папку для хранения. Всё работает через локальные модели (Ollama и Whisper), без облака.

---

## 💡 Почему решил сделать именно такой продукт

Я сам столкнулся с тем, что голосовые заметки накапливаются, и их сложно разбирать. Существующие сервисы либо платные, либо отправляют данные в облако. 
Я хотел инструмент, который работает на моём компьютере, понимает русскую речь и при этом не требует ручной сортировки. Так появился «Филин».

---

## 🛠 Что реализовал самостоятельно

*   **Интерфейс:** настольное приложение на Python (CustomTkinter).
*   **Расшифровка:** перевод аудио в текст через Whisper (`faster-whisper`).
*   **Сортировка:** генерация заголовков и раскладка заметок через Ollama.
*   **Управление голосом:** команды с триггером «Филин» (создание папок, перемещение заметок, запись текста и т.д.).
*   **Диалоги:** отдельные отложенные чаты с ИИ.
*   **История:** три журнала событий (действия ИИ, прочие события, диалоги).
*   **Интеграция:** прямая работа с хранилищем заметок Obsidian.

---

## 🤖 Какие AI / Vibe Coding-инструменты использовал

*   **AI-ассистент (чат)** — для генерации кода, отладки и проектирования архитектуры.
*   **Ollama** (модель `qwen2.5:7b`) — для работы с текстом и обработки команд.
*   **Whisper** (`faster-whisper`) — для распознавания речи.

---

## 🚀 Удалось ли запустить и какие результаты

Да, программа успешно работает локально на моём компьютере и используется в ежедневной работе. 
Она расшифровывает записи, раскладывает их по папкам в Obsidian и выполняет голосовые команды. Все процессы выполняются **офлайн**, без передачи данных в облако.

---

## ⚙️ Требования для запуска

*   Python 3.10+
*   [FFmpeg](https://ffmpeg.org/) (должен быть добавлен в PATH)
*   Установленный [Ollama](https://ollama.com/) с моделью `qwen2.5:7b`
*   Библиотеки из `requirements.txt` (устанавливаются командой `pip install -r requirements.txt`)

*(Опционально)* Для работы с заметками потребуется установленный Obsidian с настроенным хранилищем.
