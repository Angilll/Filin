# 🦉 Филин

**Филин** — настольная программа для работы с заметками на локальном искусственном интеллекте. 
Она расшифровывает голосовые записи, автоматически придумывает заголовки, раскладывает заметки по папкам и понимает голосовые команды. 
Всё работает **полностью офлайн** — данные не покидают компьютер.

---

## 🤖 Какие AI / Vibe Coding-инструменты использовал

*   **AI-ассистент (чат)** — для генерации кода, отладки и проектирования архитектуры.
*   **Ollama** (модель `qwen2.5:7b`) — для работы с текстом и обработки команд.
*   **Whisper** (`faster-whisper`) — для распознавания речи.

---

## ⚙️ Требования для запуска

*   Python 3.10+
*   [FFmpeg](https://ffmpeg.org/) (должен быть добавлен в PATH)
*   Установленный [Ollama](https://ollama.com/) с моделью `qwen2.5:7b`
*   Библиотеки из `requirements.txt` (устанавливаются командой `pip install -r requirements.txt`)

*(Опционально)* Для работы с заметками потребуется установленный Obsidian с настроенным хранилищем.

---

## 🚀 Как запустить

**1. Подготовка моделей Ollama:**
Убедитесь, что Ollama запущена, и скачайте нужную модель (если еще не сделали этого). Откройте терминал и введите:
bash
ollama run qwen2.5:7b

2. Установка зависимостей Python:
Откройте терминал в папке с проектом и выполните:
bash
pip install -r requirements.txt

3. Настройка путей (Важно!):
Перед первым запуском откройте файл notes_gui.py и проверьте переменную VAULT в начале файла. Укажите там актуальный путь к вашему хранилищу Obsidian:
python
VAULT = r"C:\Путь\К\Вашему\Хранилищу\Obsidian"

4. Запуск приложения:
В терминале выполните:
python notes_gui.py
