# Филин — локальный ИИ-ассистент для работы с заметками

**Филин** — это настольное приложение на Python, которое автоматизирует работу с заметками с помощью локальных ИИ-моделей. Оно расшифровывает голосовые записи, раскладывает заметки по дереву папок, понимает голосовые команды и ведёт диалог с пользователем.

## Что умеет

- **Расшифровка аудио.** Берёт аудиофайлы из папки `Входящие`, распознаёт речь через Whisper, создаёт `.md`-заметку.
- **Умная раскладка.** Спрашивает у локальной модели (Ollama) короткое название и папку для каждой заметки. Ты подтверждаешь или меняешь решение в таблице с выпадающими списками.
- **Голосовые команды.** Если аудио начинается со слова «Филин» — это команда. Поддерживаются: создать папку, создать заметку, записать в заметку, переместить файл/папку, переименовать, расшифровать аудио, описать папку.
- **Диалог с ИИ.** Если команда не распознана — текст уходит в чат с «Филином», где можно продолжить общение текстом.
- **Истории.** Три вкладки: диалоги с Филином, действия ИИ, прочее (услышанное, ошибки).
- **Работа с файлами.** Перенос файлов и папок, создание папок — вручную, через интерфейс.

## Технологии

- **Python 3** — основной язык.
- **CustomTkinter** — графический интерфейс.
- **Ollama** — локальные языковые модели (`qwen2.5:7b`).
- **faster-whisper** — распознавание речи.
- **FFmpeg** — обработка аудио.

## Как запустить

1. Установи Python 3.10+.
2. Установи зависимости
3. Установи Ollama и скачай модель:
ollama pull qwen2.5:7b
4. Установи FFmpeg и добавь его в PATH.
5. Пропиши путь к своей папке с заметками в файле `notes_gui.py` (переменная `VAULT`).
6. Запусти:
python notes_gui.py

## Интеграция с Obsidian (опционально)

Филин работает с обычными `.md`-файлами и папками на диске. Obsidian не требуется для работы — но если ты им пользуешься, можно встроить запуск Филина прямо внутрь.

**Что даёт интеграция:**
- Кнопка запуска Филина на нижней панели Obsidian.
- Наглядное дерево заметок, автоматически обновляемое, когда Филин раскладывает файлы.
- Удобное чтение и редактирование `.md`-заметок.

**Что для этого настроить:**
1. Установить Obsidian и открыть в нём папку с заметками (та же папка, что указана в `VAULT`).
2. Установить плагин **Script Launcher** из каталога сторонних плагинов.
3. В настройках плагина добавить запись с путём к файлу запуска (`.bat`), поставить галочку «Показывать на нижней панели».
4. Готово — кнопка запуска появится внизу Obsidian.

Obsidian — это только удобная оболочка для чтения и просмотра заметок. Вся работа Филина происходит с файлами на диске и не зависит от него.
